# Srijana Sah — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — styling and responsive layout
- `script.js` — navigation and scroll animations
- `Srijana_Sah_Resume.pdf` — resume

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a GitHub repository named `srijana219.github.io` OR any repository you want to use for Pages.
2. Upload all files from this folder.
3. In GitHub: Settings → Pages → deploy from the `main` branch.
4. Your portfolio will receive a GitHub Pages URL.

## Important
The project links currently point to your GitHub profile because the resume does not provide individual repository URLs. Replace them with direct project repository/demo URLs when available.
